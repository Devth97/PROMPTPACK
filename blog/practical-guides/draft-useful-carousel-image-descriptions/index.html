Carousels and useful social posts

Draft useful carousel image descriptions

Describe the information that matters rather than repeating a filename.

Written by PromptPack · Guide 36 of 100 · Fictional example

The methodWorked exampleReview checklistOptional AI prompt

Start with the task and the source

Move from a real audience question to a coherent sequence of slides. Use the original record, approved brief or supplied specification as your starting point. The worked example below shows one way to organise the task; replace its assumptions only with information you have checked.

  1. Write down the input and the question you want to resolve.
  2. Separate confirmed facts from missing or ambiguous information.
  3. Follow the example with your own verified inputs, preserving units, scope and source references.
  4. Complete the review check before sending, publishing or acting on the result.
Fictional worked example

Work through the example

The starting point

A fictional carousel has a diagram showing two full batches producing 24 cupcakes, with fourteen allocated to the order and ten spare. The image description currently says Slide 3 image.

What to do

Describe the meaningful relationship: two batches of twelve produce twenty-four; the order needs fourteen; ten remain. Include the relevant context and avoid adding a conclusion the diagram does not show.

What the result means

Check the description against the finished graphic after edits. If the diagram is too dense to describe clearly, simplify it rather than relying on a longer description to repair a confusing visual.

Check before you use it

Check descriptions against the finished export, not just the original outline.

Keep the original source available so you can compare it with the draft. Leave unresolved questions visible rather than filling them with guessed facts. An AI-generated draft is an aid to review; it does not perform a payment, send a message, publish content or establish a professional conclusion.

Optional prompt to organise your draft

Replace the bracketed placeholders with fictional or anonymised information. Do not paste credentials, payment details, client records or confidential family documents. Use the prompt to prepare a draft, then check it against the method above.

Draft image descriptions for these carousel slides [slide text and visual descriptions]. Preserve meaningful relationships in charts or diagrams and identify slide order where helpful. Avoid claims about details not supplied. Flag slides whose text is too dense to describe clearly without redesign.
