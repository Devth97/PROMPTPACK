Six practical workshop steps

  1. Write the style specification
  2. Draw the silhouette first
  3. Render the original example
  4. Make expressions with constraints
  5. Review transparency and contrast
  6. Package the asset family

Your first session

  1. Install Pillow: python -m pip install pillow
  2. From starter/, run: python make-sprites.py
  3. Open output/sprite-sheet.png at its native size and output/preview.png enlarged.
  4. Edit palette.json, run again and compare the silhouettes.

Requirements and scope

A text AI assistant plus a pixel editor or image generator. Manual cleanup may be needed.

The example is a small pixel character, not an animated 3D character or a finished brand identity service. LibreSprite is a separately available GPL-2.0 editor; it is referenced, not bundled. Generated examples require your own final brand review.

Try an editable prompt

Replace the bracketed fields with your own project details. This sample is part of the included prompt library.

Create a pixel art specification for an original [CHARACTER OR OBJECT] for [BRAND]. Grid: [SIZE]. Palette: [HEX COLORS]. Describe silhouette, proportions, light direction, outline rules and background transparency. Give a generator prompt and a manual cleanup checklist. Keep edges aligned to the pixel grid and avoid blur, gradients and anti-aliasing. Return variations for neutral, active and resting poses using the same proportions. Do not imitate a named artist or an existing character.
