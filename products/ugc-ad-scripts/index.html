Six practical workshop steps

  1. Build a demonstration worth watching
  2. Translate references into a style lock
  3. Write a hook the body can pay off
  4. Direct the shot and the presenter
  5. Review what the viewer will believe
  6. Hand off a controlled experiment

Your first session

  1. Read the six-board example and fill the master brief with one product task and supplied evidence.
  2. Translate three inspected references into an original style lock; approve one hook and one prototype shot.
  3. Use prompts 01-11 to produce the script, six scene briefs and presenter/recording handoff; rehearse with the real product.
  4. Optional: run prompts 15-22 to turn the six briefs into AI video cuts with one style header and a blocking map, while every claim stays on real footage.
  5. Optional: install the ugc-ai-ad-studio skill in Claude to run a reference-led AI ad through decode, reference sheets, stress test, one timed prompt, one take, a film finish in code and sign-off.
  6. Run the quality gate, inspect the placement crop and export the approved files with captions, source ledger and a blank test plan.
