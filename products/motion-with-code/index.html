Try an editable prompt

Replace the bracketed fields with your own project details. This sample is part of the included prompt library.

Inspect the animation project and use its existing framework. Create a six-second title card for [TITLE] in [WIDTH x HEIGHT] at [FPS]. Define a single deterministic timeline: title enters at 0.4 seconds, supporting line at 1.2 seconds, both hold until 4.8 seconds, then exit by 5.6 seconds. Expose copy and colors as variables. Use licensed local fonts. Make arbitrary-time seeking produce the same frame as sequential playback. Return file changes and checks at 0, 1.2, 3 and 5.6 seconds. Do not claim a render exists until it has completed.
