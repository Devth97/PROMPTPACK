04 / STORE SETUP

What you’ll need to go live

A Shopify store, a Razorpay account, an SMS provider for OTPs, and a host for the Node payment functions. Other storefronts require adapting the order integration.

  1. Pick a layout and brand it. Set your logo, colour, delivery fees, COD rules and coupons in one config file, or ask the skill to do it.
  2. Deploy the small server. Add your Razorpay keys and a Shopify custom app token as environment variables.
  3. Add the snippet to your theme. Your cart and buy-now buttons open your checkout. Shopify's own checkout stays as a fallback.
  4. Test in Razorpay test mode. Place UPI, card and COD test orders and check they reach Shopify.
  5. Switch on live keys. Run it next to your current checkout first if you want to compare.

Questions

Do I need Shopify Plus?

No. Your checkout runs before Shopify's and creates the paid order through the Shopify Admin API with a custom app, which works on every plan. Shopify's own checkout stays available as a fallback.

Does it work outside Shopify?

Yes. The checkouts are plain JavaScript and take any cart. The server includes Shopify order creation; for WooCommerce or a custom store you swap that one function for your platform's orders API. The skill can do that swap with you.

Does it work with Razorpay, UPI and COD?

Yes. Prepaid orders go through Razorpay Standard Checkout in your own account (UPI, cards, net banking, wallets). Cash on delivery skips the gateway and creates a pending order, with your COD fee, limit and blocked pincodes applied on the server.

Are prices safe from tampering?

Yes. The browser only sends product IDs and quantities. The server looks up prices from your store, applies the same rules, and creates the Razorpay order for that amount. Orders are only created after the payment signature is verified.

Is the OTP real?

The demo fakes it. The kit has the OTP flow and server endpoints; you connect an SMS provider of your choice, which charges per message. On Android Chrome the code can fill itself from the SMS.

Will I lose saved addresses from my checkout app?

Addresses saved inside another app's network stay with that app. Shoppers type their address once with you; the pincode fills city and state to make that quick.

What about conversion tracking?

The checkout calls your code when an order completes, with the order number and value, so you fire your Meta Pixel, Conversions API or GA4 purchase event yourself. The guide shows where.

Is anything charged in the demo?

No. The demo stores are made up and the payment step is simulated.
